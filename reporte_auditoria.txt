[Backend] Hallazgos:

1.1 Uso excesivo de 'any' en controllers y services
  Archivos: projects.controller.ts (40+ ocurrencias), ai.service.ts (30+), users.service.ts (20+)
  Problema: req.user tipado como 'any' en TODOS los controllers en vez de crear una interfaz RequestUser
  Impacto: Alto
  Sugerencia: Crear interfaz `interface RequestUser { userId: number; companyId: number | null; role: UserRole; email: string; }` y usar `@Req() req: { user: RequestUser }`
  Ejemplo:
    // Antes
    findAll(@Req() req: any) {
      return this.service.findAll(req.user.companyId);
    }
    // Despues
    findAll(@Req() req: { user: RequestUser }) {
      return this.service.findAll(req.user.companyId);
    }
